# 外部首读

<!-- reader-prompt:begin -->
你是一位第一次接触这份稿子的读者。你没有看过原材料，也不知道作者打算怎么写。任务是从头读到尾，记录自己的阅读感受，不负责改稿。

任务发起者只给你：目标观众是谁、对题材有多少了解、文字将用在什么地方、草稿正文。没有提供的读者属性不要编。不要读取原材料、写作方案、评分标准或其他读者的反馈，也不要找外部资料补理解。

按顺序读，每段停一下。用短段落记录哪里被吸引、哪里开始走神、哪里没看懂、心里挂着什么问题、哪里需要硬撑着读。每条贴出让你产生这个感受的原文；没出现某种感受就不凑。后文解开疑问时，记录在后文，不倒回去假装前面已经懂了。

可以这样记：

读到“【逐字摘录】”，我想知道【具体问题】。
读到“【逐字摘录】”，我不知道【人、东西或动作】指什么，只能先往下读。
读到“【逐字摘录】”，前面的问题有了答案，我开始关心【下一件事】。
读到“【逐字摘录】”，这里接连出现几个词，我需要停下来回看。

不写“建议”“应该”“改成”，不给替代句，不打总分，不判断事实真假，不推测真实用户的反应。读完后再回答这些你自己就能判断的问题，仍贴原文作依据：
- 读到哪里开始想知道后面？一直没想知道也直说。
- 你希望这个人接下来怎样？没有期待也直说。
- 记住了哪个画面或动作？
- 哪里开始走神？哪里没听懂？
- 看完得到了什么？可以是一个认识、一种感受，也可以是没得到什么。
- 你会不会转给谁，为什么？这是你本人的选择，不猜群体反应。
最后说仍然没弄明白的事。
<!-- reader-prompt:end -->

## 外发范围与预算

改稿时用 DeepSeek 首读；只有当前用户／任务对该服务及发送内容有可核验授权，并符合隐私与预算时才执行，不能沿用未经核实的“长期授权”。只发正文、任务受众与知识范围、形式与已定长度（未定写未定）和上面的固定读者指令；原材料、看点、工作表、设计、方法、评分、会话、密钥和本机路径不发送。其他外部服务不在这项授权内，不自动建立公开临时链接。

授权不明、未公开采访、私聊或他人隐私未获相应许可时，先说明范围并征求同意；作者不同意外传或用户明确不外发时停止外发，不反复争取授权。等待时先做念一遍和核有没有改歪，不能把未调用说成完成；写作委托不自动包含外发许可。

每个任务目录默认最多6次请求，单次通常不到1分钱，这只是既有经验而非当前计价保证。已发起的失败也占次，用量未返回不推定免费；超额须先获用户明确授权。共享预算优先于单任务默认额度，程序不自动重试、不查余额、不换服务。

## 送什么，何时送

第 4 步每一版的初稿各送一次，读者反馈当改稿的证据。本轮删改若改变前提、指代、关键答案或信息承接，改后稿再送一次；段内删句也可能触发，不以段落数量是否变化判断。不影响这些关系的措辞、标点或排版修改不因此增加调用。默认最终正文一稿，只有两个不同且有用的看点才给角度备选；用户明确要同点长短版可照做，默认总数不超过两版，显式更多另按范围。不自动扩成两看点×两长度。所有版本共用本任务预算，先给需要复核的交付稿预留次数，默认总上限仍是六次；增加版本不静默增加额度。

每一编辑轮因上述条件最多增加一次改后首读，按反馈局部补修后不再自动送读；反馈取舍和补修核对按改稿页第 5 节执行。

用户挑中后提了意见，改完那一版送一次（这一轮改前不送，也不因上述条件再叠加）。只改开头、结尾的任务，送最终交付的那一版；改现稿的任务，改前的现稿送一次，涉及上述理解关系改变的，改后也送一次。只改标题或封面不送。只交诊断、大纲、讲法或建议不送。每份文字单独一个请求，不把几版混给同一位读者。

初稿返回后和审稿员的意见一起，按[改稿](../references/revision/index.md)合并修改；改后首读的反馈按改稿页第 5 节取舍，用户提意见后那次按“用户提意见后的那一轮”处理。只要正文时，过程记录留任务目录，但影响采用的未审状态或关键事实缺口须在正文外用一句必要说明保留。

读者画像按实际任务沿用受众和已知知识范围，已知不重问、未定写未定；不能把写作时的作者假设说成用户已给的读者属性。起草时的解释处理仍按[新读者规则](../references/story-checks.md#新读者改写规则)，送读不默用脚本默认画像或两分钟形式。初稿、改后稿和用户反馈轮均使用[任务参数](../references/script-usage.md#审稿员)中的 `TASK_AUDIENCE`、`TASK_MEDIUM`，只抽取读者属性，不把来源、看点或工作表整包传入。

## 执行

```bash
python3 scripts/run_first_reader.py --task-dir "$TASK_DIR" --draft draft-30-初稿.md --audience "$TASK_AUDIENCE" --medium "$TASK_MEDIUM" --allow-external
```

任务目录用绝对路径；相对稿件路径从任务目录解析。已有配置交脚本读取，不查看或打印密钥。`--allow-external` 表示已按上面范围核实可发。

以实际 HTTP 返回为外部首读收到反馈的依据：HTTP 200、非空正文且正常结束才形成有效反馈。没有有效返回则记“外部首读未完成：原因”；超时、空返回或旧稿意见都不算本轮完成。返回只代表这次模型首读，不是事实核验或真实观众测试；改后稿不沿用旧版本的确认。

外部模型不可用时，可在允许范围内用本工具的干净上下文，给同一固定读者指令、任务读者属性和正文，记“同模型干净上下文替代；外部首读未完成”。不能让替代上下文读源文、看点或起草会话，也不能借替代绕过禁发。干净上下文也不可用或不许发送时，记未完成原因，只做本地核查，不换服务、不读凭据、不自动重试。

外部首读不是用户明确交付前提的，本地核查后可交稿并标未完成；是明确前提的，保持待审，不称最终验收。记录分开写提示生成、本轮非空反馈收到、作者采纳修改、改后复核所对应的版本与结果，不能用前一阶段代替后一阶段。

脚本自动保存请求、送审正文、脱敏响应、用量、回执与反馈；故障时保留实际状态。配置顺序、共享账本、限次、超时及恢复细节见 `run_first_reader.py --help`。
