# 内容评估与维护结论

2026-10-30。本记录回顾导入后的内容试验、流程修补和文档归并，供维护时查阅，不加入每次写稿的必读步骤。现行用法以 [SKILL.md](../SKILL.md) 及其引用文件为准。

## 总结

目标是根据材料写出适合短视频的口播或脚本，不是小说生成器或手机 App，也不以完整复述经历代替观看价值。准确、讲清楚和保留事实边界是底线，但不能替代继续听下去的理由；不因此强制两分钟、成功结局、反转或分镜表。

本轮实际采用的是流程契约与可靠性修补，以及三处文档归并。内容试验没有形成可纳入默认流程的新写法；“成稿稳定更自然、更值得听”尚未证明达到。工程检查、文字变短和内部阅读偏好都不能代替这一结论。

## 已采用的范围

- **任务信息与决定权**：起草、首读和审稿沿用实际受众、已知知识范围、形式与长度；不把所有任务改成普通外行、两分钟口播。用户选择、作者受托决定、作者假设、已问待答分别记录。委托可以在范围内继续，开放选择不能以沉默代答，缺失事实不能默认发生。
- **稿数与长度**：默认一稿，正常最终备选总数不超过两稿；用户明确要求更多时另按请求。看点备选与同点长短版不自动相乘，也不为凑短版删除核心责任、条件或完成状态。
- **审查与交付状态**：提示生成、有效返回、作者修改、改后复核分开。未完成的审查不能报通过；用户要求审完才能定稿时停在待审。只要正文可省过程表，不能隐藏必要事实缺口、未审状态，以及既有适用条件下的署名、归属和待确认发布授权。普通第三人称叙述不自动套用代言许可。
- **信息隔离与外发**：首次阅读者仍不见源材料、看点和预设答案。外发、转写与付费沿用当前用户和任务的可核验授权，历史许可不自动跨任务生效；缺授权不自动公开材料或切换服务。
- **可靠性修补**：输入及输出位置预检、任务属性传递、可保留的脱敏异常和部分返回留证、请求尚未开始时的本地授权次数恢复已采用。路径保护共用 [`scripts/_review_safety.py`](../scripts/_review_safety.py)。次数恢复须有未开始的证据并保留失败记录；已尝试或状态不明仍计数，不自动重试。这只恢复本地授权次数，不是供应商退款证明；路径保护也不是操作系统沙盒或完整文件系统安全保证。
- **三处文档归并**：起草细则集中到必读工作表；逐轮反馈、取舍与核查详情集中到对应改稿记录，工作表保留具体版本状态与入口；完整交付按版本只说明一次用卡理由、作用位置和必要限制。三文件合计减少338个Unicode码点、1048个UTF-8字节；未减少独立审查、调用要求或事实核对，也未证明实际节时、省费或成稿效果等价。

具体用法见[工作表](../templates/story-workbench.md)、[改稿流程](../references/revision/index.md)、[首读说明](../agents/first-reader.md)、[交付模板](../templates/voiceover-delivery.md)、[改编说明](../references/adaptation.md)与[脚本说明](../references/script-usage.md)；此处只记采用范围，不另设日常操作步骤。

| P1/P2与新材料D | P1筛选哪些问题进入正文，P2检查逐段是否增加理解，均实际执行但未正式采用。P1在A的局部聚焦伴随选卡、工具差异；P2仅有局部删句，主要重复仍在并暂停。D在共享看点下测试P1，聚焦同时损失人物关系与情绪层次，不能以更短或未发现失真判整体胜出。 |

| F：写前组织 | 调整确实进入提示和正文，但主体仍按操作经历推进，结尾集中列未完成事项；两稿再次未达到委托方继续听的要求，不采用候选。双方都排除了依赖过程画面的写法，不算候选独有收益。“守住事实不等于逐项念防错说明”是诊断，不是已验证的删限定许可。 |
| 行业与全链路调研 | 调研形成材料取舍、呈现条件、反馈回到上游三个待测方向。外部经验不直接当成已验证规则，随后以G/H1、H2、H3检验；调研本身不证明效果。 |
| G/H1：正文必要信息、可选展开与写作约束 | 写前取舍确实改变了正文，但两份内部阅读的微弱偏好相反；少解释也损失费用、身体感受等层次，无明确稳定收益，不采用、不追加材料追求胜者。 |

| H3：反馈回到上游 | 局部集中获得正向文字反馈，但相关删改原规则已允许，对照上下文不对称；关键的收窄范围或重选重点分支没有触发，既不能报通过，也不能判该分支失败。不采用，不再抽新材料。 |

## 未解决、未触发与未验证

- **质量目标未解决**：本轮实际样例中仍可见重复说明、事实覆盖压过观看价值、焦点与人物层次取舍的问题，不能泛化为每篇都会发生。后来的模型偏好不覆盖委托方对E/F的否定；没有复测提分或普遍成稿提升结论。
- **画面条件漏项未修**：另一次受限作者演练的B、D、F情境（不是上表同名内容试验）在画面可用性未知时采用依赖过程画面的写法，没有解决条件即起草；未修复、未重测。不能倒写成已知无画面，也不能用H2的显式提示结果证明日常执行已修好。
- **分支状态不同**：C是停止条件已生效；P1/P2及H1等是试过而不采用；H3上游重选是未触发；普通第三人称不应额外索取代言许可的对照是未实际执行。不能互换这些状态。
- **验收覆盖有限**：决定权、稿数和未审出口有受限作者执行证据，但不是脚本、读卡、独立首读与全部审稿联动的完整链路。普通第三人称授权对照只作静态规则核对；文档路径检查也不证明所有作者都会照做。
- **终稿与审查版本不完全等同**：G原对照终稿最后补了三个字后未再独立送读，H3引用该对照时仍保留此限制。局部复核不冒称全篇重新通过，共享反馈不重复算新增审查。
- **效果与成本没有实测**：内容评估主要使用合成材料和同模型文字阅读；没有真人目标观众、实际口播、真实声画或传播效果验证，没有已连通外部跨模型全链路的证据。文字估时不是朗读，混合了写作与留痕的时长不是净创作成本。
