# story-craft

把跟人和事有关的材料（帖子、复盘、采访录音、零散经历、身边人的事、一门生意怎么赚钱）写成故事口播或故事脚本；也用于给这类材料挑讲法、修改手里有原材料的人物故事稿。

本仓库保存当前技能的完整私有快照：入口、脚本、模板、故事卡、写法卡、方法快照与改稿手册均在内。技能文件与上传时的本机版本逐字一致，具体清单与指纹见 [导入记录](docs/repository-import.json)。

## 入口与内容

从 [SKILL.md](SKILL.md) 开始，按五步处理：盘点素材、匹配卡片、构建写稿提示、审稿与修改、交付。

- [故事卡与写法卡目录](references/story-cards/index.md)：18张故事卡、43张写法卡。
- [工作表](templates/story-workbench.md)：看点和观众会先问的问题、候选、关键事实原句与限制、每段安排。
- [改稿流程](references/revision/index.md)：八位审稿员按改稿手册分组审，另有一位用意审稿员逐句、逐段问想让观众明白什么；写稿方统一取舍和修改。
- [脚本说明](references/script-usage.md)：读卡、估时、引号数字核对、首读和审稿命令。
- [外部首读说明](agents/first-reader.md)：实际送审范围、时机、预算和版本记录。

包含近期改进：影响理解关系的改动后复核；关键事实原句进入写稿提示；审稿意见区分“必须修、待核原文、可选增强”。

2026-10-29 更新：

- 没定长度不再默认两分钟：排完段落装不下，先缩小这篇要讲的范围，还装不下再问长度，或交完整版和两分钟版。
- 新增用意审稿员（第 10 位），只拿稿子，逐句、逐段判断观众能不能自己说出这句想让他明白什么。
- 定看点时，列出没读过原文的人会先问的问题和回答它们的原文位置，作为写稿时不能省的信息；分段时每段要么推进看点，要么回答这些问题。
- 素材清单的“看点”改成“看点候选”：十个方向只作检查提醒，只列材料撑得起的两三条，每条写清哪件事、谁在意、想知道什么、原文位置。
- 技能说明写明什么时候用、什么时候不用，和 media-script-review 划清边界；删掉重复和指向旧入口的说法；整篇被否时先分清是看点不对还是没讲明白。
- 写法卡要先说得出用在哪一段、改这段的什么、用哪条素材才配；分段计划每行写清用了哪张写法卡，整篇组织卡写它管的段落范围。起草时写人物特点或下评价，先用材料里撑得住的具体动作或细节。

## 安装与使用

仓库根目录就是技能目录。新环境可以将本仓库克隆到客户端使用的技能目录；例如本机 Codex 使用的路径：

```bash
git clone https://github.com/guasi18587278913/story-craft.git ~/.codex/skills/story-craft
```

目标目录已存在时，先检查已有内容再合并更新。Claude Code 也可以使用同一份技能目录；本次上传没有修改本机已安装目录及其现有链接。

调用示例：

```text
用 story-craft，把这份公开自述整理成故事口播。
保留事实与作者立场，未发生的结果不要补。
```

任务素材、草稿、审稿反馈和请求回执放在仓库以外的持久目录；脚本的任务目录参数使用绝对路径。

## 运行条件

- 辅助脚本使用 Python 标准库；本机以 Python 3.9 验证。部分脚本依赖 `fcntl` 和 POSIX 信号，Windows 原生环境未适配。
- 跨模型审稿需要可用且已登录的 `codex` 或 `claude` 命令。`--prompts-only` 仅生成提示，不调用模型。
- 外部首读需要用户自己的 DeepSeek 凭据。脚本支持环境变量 `DEEPSEEK_API_KEY`、指定密钥文件或用户目录下的本地配置；完整顺序见 `run_first_reader.py --help`。仓库不包含凭据或登录态。
- 实时知识库通过 `gbrain_sc_media`／`sc-media-kb` 的只读 `get_page` 访问。本仓库包含已标来源的本地卡片与方法快照，不包含MCP服务或完整知识库；未实时查库时按技能规定说明。
- 音视频输入的转写依赖技能正文引用的 videocut 工作流，它没有打包进本仓库。纯文字流程可直接使用这里的文件。

## 检查

下面的命令只做本地结构与内容完整性检查，不调用外部模型：

```bash
python3 -B scripts/check_integrity.py
```

原句、数字的匹配和文件检查不能代替事实核验、写作质量判断或真实观众测试。外部首读和审稿需遵守各自范围与预算，不能将有文本返回等同于建议正确。

## 资料与配置边界

课程、书籍和示范稿保留原出处及引用边界；本仓库未为第三方内容授予开放转载许可，因此这次采用私有仓库保存，也没有添加统一开源许可证。

技能中关于长期授权、知识库服务名和转写方式的说明属于当前使用者的配置约定。复制到其他账户或环境时，需要按该使用者自己的授权和配置执行。本次任务产生的稿件、个人聊天导出、密钥、模型回执及本机实验目录不随本仓库上传。

当前仓库与本机已安装技能是两个目录；后续编辑不会自动同步，也没有设置自动推送或CI。
