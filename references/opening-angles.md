# 开头角度：多版开头要换角度，不是换说法

用户要几个开头（默认 3 个，最多 5 个）时，每版必须来自下面不同的角度，标出角度名。同一个角度换个措辞不算新的一版。每版第一句都要有具体的人、物、动作或数字，不用“你知道吗”“今天讲一个故事”起手。材料撑不起某个角度就不用它，宁可少给。

| 角度 | 怎么开 | 材料里要有 |
|---|---|---|
| 现场 | 直接落在一个动作或一句原话上 | 有时间、动作或原话的一刻 |
| 反差 | 并排摆出前后、身份与行为、预期与结果 | 两头都有事实 |
| 改判 | 先说大家熟悉的看法，再说这看法只对一半 | 能推翻或补全它的事实 |
| 问题 | 抛出一个观众想知道答案的具体问题 | 正文能完整回答 |
| 物件 | 从一个小东西切进去（棺材、纸条、截图） | 那个物件真实存在并贯穿 |
| 代价 | 先说这件事让谁付出了什么 | 说得出的具体代价 |
| 关联 | 从观众身边的事接到这件事 | 关联真实，不硬扯因果 |

主推一版放第一，写一句为什么主推；其余写一句各自适合什么时候用。思路参考 story-studio（MIT）的开头分类，表格为本技能自写。
