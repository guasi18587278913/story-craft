# 来源导航

按当前问题回查，不在普通创作中加载全部来源。本 Skill 是对用户自媒体知识库的综合整理；卡片、练习和判断表中有编辑归纳，不冒充原作者原话。原文用 `gbrain_sc_media.get_page(slug)` 读取；研究缓存只用于核对历史研究证据，不直接读取 Wiki 正本。

## 当前使用入口

- 工作边界与任务路由：`workflows/creation_teacher`。
- 选材和角度：`workflows/topic_planning`、`methods/playbook/playbook-topic-divergence`。
- 故事基本概念：`concepts/storytelling`。
- 结构：`concepts/structure_quick` → `concepts/structure` 中选中的条目。
- 开头：`concepts/opening_hook_quick` → `concepts/opening_hook`。
- 正文：`concepts/body_expression_quick` → `concepts/body_expression`。
- 结尾：`concepts/ending_quick` → `concepts/ending`。
- 标题封面：`workflows/title_packaging`、`concepts/title_cover_quick` → `concepts/title_cover`。
- 保存作品与反馈：`workflows/creation_archive`。保存需用户授权。
- 现稿诊断：`workflows/work_diagnosis`；用户明确要求发布后复盘时读 `workflows/performance_review`，无后台数据则回到内容诊断。

先看相应速查页，按其提示读选中写法、禁忌与不照搬。清单编号只作库内定位，不必在交稿时展示。
