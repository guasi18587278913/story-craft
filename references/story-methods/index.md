# 故事方法导航

编号沿用知识库。它们是遇到具体问题时的补查材料，不是写稿前的固定阅读包。先读相应速查页，再取所选编号与禁忌。专名泛化过的条目分别保留原段和存入指纹，位置记录见出处文件；缺条目用 get_page 读原页。

| 环节 | 快照范围 | 同时读 |
|---|---|---|
| story | all | 整体概念有需要才读 |
| structure | 23–34、35、46 | 通用禁忌；缺口按需 |
| opening | 29–33、2、3、4、9、22 | 通用禁忌 |
| body | 1、8、16、19、21、22、26、27、28、33、34、38、41、49、50 | 不照学；收稿读写完自查 |
| ending | 4、10–16 | 照单全收 |

[路由目录](../story-cards/index.md)用于选卡；[读卡与核对](../script-usage.md#读卡与核对)提供命令与记录格式；[出处](provenance.json)保存原页指纹。改稿时看[改稿](../revision/index.md)，整篇案例只放在对应的故事卡里。

修具体的节奏毛病时，按需读正文 30–37 条（删重复、单一重点、递进、句长与段尾）。这些编号不在既有快照时，用 get_page 取相应编号再记录，不把“本包没有”当成库里没有。
