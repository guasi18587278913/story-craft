# 找看点、读齐材料、给候选卡补料

## 找看点

故事卡的骨架多半按时间排，材料又常是一整段经历。匹配卡片前不先想清“观众最想看的是哪一点”，照骨架写出来就是流水账：观众不知道在讲什么，也不知道和自己有什么关系。这一问在匹配卡片时先答：用户已给角度就沿用；明确委托整稿但未锁角度，正常选讲述重点并记作者受托决定，不反复问；未给非关键偏好且未问出待答选择，可合理默认并记作者假设。若已向用户问出会影响后续的选择或开放卡，未答只做不依赖答案的工作，不代选、不给依赖它的最终版。选择讲法不等于授权付费或外发，事实缺口不能假设发生。

**三问**

- **写给谁**：用人群的说法，不用行业词。不提行业词的“人群选题”让更多人对得上号，提行业词的更精准但人少（知识库 `methods/method_principle/method-3b21774f67453652`）；行业经历可以留着当反差，不当话题。说清这群人现在什么处境、心里在想什么。
- **靠什么抓人**：共鸣、利益、好奇，主抓一个（知识库 `sources/community/zsxq-14422154145122452` 第 2 章）。共鸣是“场景加情绪”；利益要具体到钱、时间或省掉的麻烦；好奇是没听过的事或颠覆认知的事，正文必须兑现得了。
- **有没有一句能转述的硬成绩**：数字或看得见的变化，口径写清，报价、预算、到账分开。成绩薄的标出来，没有就不硬凑。

能回答这三问的，从第 1 步标的[看点候选](../templates/material-checklist.md#看点候选)里挑：各条候选是不同的观看理由，到这时才比较、选一个。上述三问及本地卡片可直接用于找看点。`methods/playbook/playbook-topic-divergence` 是可选回查出处；仅在用户已配置并选择在线 Wiki 时读选中方法，不因缺少该服务停下本地流程。

**写下来**

在工作表“看点”一栏写一句：这篇只讲哪一点、写给谁、靠什么抓人、哪条事实兑现。兑现的得是材料里发生过的事、做过的动作或数字；只有当事人的判断撑着的（比如“这不是好事”“这行不值得做”），把看点收窄到这个判断本身，讲他为什么这么看、做了什么，或者换一个看点。看点答应观众的是“做成了”“管用”的，兑现的还得是证明做成了的那件事，不能只是证明难题存在的事；材料里只有日常做法的说明或作者举的例子，没有一件真事证明做成了，算缺口，和候选卡的缺口一起补料、问用户；补不上，就照实讲成“TA 的做法是……”，不说成已经做到。再列观众会先问的几个问题：没读过原文的人听到这一点，会先冒出什么疑问，每个问题标上原文哪段能回答。这些是写稿时不能省的信息，分段计划里要有段落回答它们；它们本身不抓人，也不能当背景删掉。用户已经给了角度或标题，就用用户的。用户提的说法里有材料没有、或比材料说得重的事实（年龄，“失业”这类身份，没到账的钱），不照用，告诉用户原文怎么写，按原文写。

合成示例（不是真人真事）：材料是一位面馆老板一年的复盘。“开店一年的经历”不算看点；“一碗面涨了两块钱，回头客反而多了”算一个：写给开小店的人，靠好奇和利益抓人，兑现它的事实是涨价前他先做了哪件事。没读过原文的人会先问“涨了哪碗面、涨到多少”，这条材料写稿时就不能省。

**定了以后**：选卡时找撑起这一点的主线；写稿提示把这一点和观众问题放在最前面；和它无关、也不回答观众问题的经历，在材料里占得再多，也一句带过或不写。默认一稿；两个不同且有用的看点才给角度备选。两版不同看点仅约束角度备选，不排斥用户明确要同点长短版；默认最终正文总数不超过两版，显式更多另按范围，不自动做两看点×两长度。两看点都超过约定时长，先按授权选主推再处理长度，有开放选择则等答。

## 材料指向别处的，先读过来

复盘、帖子里常有“具体经过我另写过一篇”“详见附件”“视频里讲过”这类话。被点到的那一份，往往正是故事最要紧的经过：那件事具体怎么发生的，谁在哪一步做了什么，对方怎么回。盘点素材时就去读，不等到补料才想起来。

1. 只读被点名的那几份：标题、链接、附件名对得上的才读，不顺着作者主页一路扩。
2. 免费能读的直接读，原样合进 `source.md`，标明材料编号、标题、读取方式和日期；图片、视频读不到内容的写明没读。
3. 要登录、付费、作者没公开或找不到的，记成缺口，匹配卡片时跟其他缺口一起问用户；付费的先报次数和费用。读取失败如实记，不当作那份没有内容。
4. 几份说法对不上（金额、时间、先后），各自记下出处；写稿时写清用的是哪一份的说法，拿不准就问用户。

## 给候选卡补料

只补候选卡要的，不把所有卡可能需要的材料都找一遍。从候选卡对不上的条件开始，记录“哪张卡→缺哪个事实→缺了会怎样”。例如折腾经历缺“第二次尝试的结果”，就问第二次到底发生了什么，不问泛泛的“还有什么细节”。

先分清两种缺口：

- **缺了故事就不成立的事实**：卡片“缺了就不成立”里的那些，比如没有行动、没有转机、没有结果。补不上就换卡；换到哪张卡都要重核它的条件，换卡不能绕过同一个事实缺口。
- **缺了只是不够生动的细节**：原话、画面、物件、数字这类。补不上就略写，不编。

## 先查，再集中问

1. 列出可读范围、计划渠道与预计费用。免费可访问的原帖评论、作者其他帖子、用户给的链接先查；只找能补这个空段的内容，保留出处、作者和位置。陌生评论不能直接当作当事人经历。
2. 需要付费工具或次数不明时，先报预计调用次数、费用上限和停止条件，获得同意后再查。读取失败如实记失败，不能当作没有内容。
3. 已有渠道仍缺的，一次性问用户。每问对应一张候选卡缺的一项，写明记不清或不愿公开也可以这样回答。
4. 问了仍没有、无法回复或不愿回答时：事实缺口仍按缺处理，不假设发生；可以先做不依赖回答的整理和候选核查。已问出的关键选择、开放卡或待同意操作未答，不以沉默代选或授权，不生成依赖该答案的最终版。用户明确不能补或在既有授权内处理不依赖答案的部分时，缺的是细节就略写；缺的是“缺了就不成立”的事实，就换准入条件满足的卡，或者告诉用户这份材料还缺什么。把影响留在稿外。删并后重核前后因果，不能删掉会改变责任或结果的事实。

## 按空段提问

| 空在哪里 | 具体问法 | 用处 |
|---|---|---|
| 起点只有“很难” | 那次哪件事做不下去？你当时正在做什么？ | 把形容词还原为一次事件 |
| 尝试没过程 | 你先做了什么？对方随后做了什么？ | 问行动与反馈 |
| 几次经历混在一起 | 这两句话说的是同一次吗？两次之间发生了什么？ | 分清轮次与时间 |
| 转机只写“后来想通了” | 你是看到、听到或做了哪件事后改了决定？ | 找新信息，不预设贵人 |
| 结果只有“效果不错” | 当时具体完成到哪一步？还剩什么没解决？ | 区分完成和计划 |
| 配角只有标签 | 你说他支持你，记得他做过哪件小事吗？ | 用行动解释关系 |
| 原话或心理不明 | 这是你当时说过的，还是现在回看时的理解？对方有亲口解释吗？ | 明确归属 |
| 有作品没来由 | 这个形状或细节是谁提的？试过别的做法吗？ | 让物件接到选择 |

问法依据：李诞 `sources/book/lidan-68886b2154cae209` 的前采方法提出“问事实，别问想法；问行为，别问理由；问事，别问人。”此处用具体问题帮助回忆，不把它当作禁止谈感受的规则。先看已有材料中的语气和经历，再问真正缺的那一格。

自然流课程 `sources/course/xuehui-f2c49c38d620509e` 的 00:43:38–00:46:52 提醒：听完一个切点再问下一个，不强迫背提纲，也不以辩论方式逼答案。`sources/course/xuehui-ce292d65d77eb067` 的 00:12:24–00:14:24 对应保护表达状态。“发心—困难—破局—规划”这类采访提纲只用来定位缺口，不能代造问答。

作品类追问可参考 `sources/course/xuehui-1c0f67cddff9ac1f` 的 00:36:04：从作品形状、小细节、启发和当时经历问起。假设问题得到的回答只代表假设，不改写成已发生事件。

合成例子：材料只有“面包没发起来，我把面粉重新称了一遍”。可以问“重称之后发现了什么”，也可以照实只写一次，不凑第二次失败；不能直接添一个坏烤箱。可创作什么、必须回材料什么，统一见[材料边界](story-checks.md#材料边界)。
