# 路由目录

两层卡：故事卡决定讲什么样的事、整篇怎么排；写法卡管怎么组织、怎么表达。先选故事卡，再配材料撑得起的写法卡，一起放进写稿提示；改稿时再按诊断查写法卡。

## 一、选故事卡

1. 先问：这份材料里，目标观众最想看的是哪一点？答法见[找看点](../materials-and-angle.md#找看点)。再按下面六组，找撑起这一点的主线落在哪一组。
2. 在组里按“主线看哪里”挑；也可以跨组，候选最多三张。
3. 每张候选逐条对“缺了就不成立”。缺一条，先看能不能补；补不上就不选这张，不放宽条件。下面表里的条件是缩写，候选卡都要读整张卡，按卡内原文再核一遍，以卡为准。
4. 表里“对不上时改看”只是指去哪张卡再查一遍，依据是手里还有什么材料。到了那张卡，照样逐条核它的“缺了就不成立”；换卡不能绕过同一个事实缺口。
5. 一张都对不上，看第三部分。

### 跨组最容易混的几对

| 两张卡 | 怎么分 |
|---|---|
| 困境转机／折腾经历 | 困境转机讲被挡住、再熬过去，不追问原因；折腾经历一直在找原因 |
| 折腾经历／过程记录 | 折腾经历的每一步是失败后再找原因；过程记录的每一步是往前做 |
| 折腾经历／检讨共鸣 | 折腾经历是坏结果之后几次找原因；检讨共鸣是一件小错加一次反省 |
| 苦难经历／困境转机 | 苦难经历讲苦难怎样影响生活、现在怎么看待；困境转机讲怎么熬出来，要有看得见的成就。不按苦难能不能改变来分 |
| 人生选择／回应偏见 | 人生选择从我的决定出发，别人的看法只占对比那一段；回应偏见从别人的质疑出发 |
| 回应偏见／平凡英雄 | 回应偏见是不理会议论、照样过；平凡英雄是对一件不公的事出手讨说法 |
| 平凡英雄／检讨共鸣 | 错在别人，出手讨说法；错在自己，认错补救 |
| 热点＋我的经历／平凡英雄 | 热点是旁观外面的事，拿亲历表态；平凡英雄是自己当事、自己硬刚 |
| 从一件事看懂一个现象／后知后觉的爱 | 前者主线是很多人都有的通病，身边人只是例子；后者主线是那个人和他的付出 |
| 我帮别人成了事／拿自己做成的案例拆方法 | 前者看对方的起伏和我出手那一刻；后者把方法一条条拆开 |
| 讲别人怎么做成的／拆别人的生意怎么赚钱 | 前者有一个人卡住又过去的经过；后者拆赚钱链条，可以没有主人公 |
| 替你去体验／过程记录 | 按主线分，不按有没有成品分：体验看替观众试一回的亲历感受和认识；过程记录看一件事怎么一步步完成。体验陶艺做出杯子，主线是试一回的感受，仍归体验 |

## 二、写法卡：匹配时配上，改稿时按诊断查

## 三、一张故事卡都对不上

先分清是哪种情况，两种的处理不一样：

1. **缺料**：缺的是“缺了就不成立”的事实，比如没有行动、没有转机、没有结果。先补；补不上，换哪张卡都一样缺，整篇组织卡和三幕式也补不出这些事实。直接告诉用户：当前材料缺什么，可以去问谁。
2. **材料齐，但不是这 18 种故事**：可以从下面这张名单里挑一张整篇组织写法卡当骨架试写；局部表达卡不能当骨架。照样逐条核那张卡的准入条件，满足才写，交稿时标明“照骨架试写，没有完整案例可照”：
   - 两件都重要，只能舍掉一件 → [两难见人](../writing-cards/LX24-两难见人.md)
   - 几个人各知道一部分，试过错路才拼出答案 → [拼图揭谜](../writing-cards/LX23-拼图揭谜.md)
   - 追求在经历中变了 → [目标转向](../writing-cards/LN08-目标转向.md)
   - 好好的生活被打断，努力恢复原样 → [生活被打断](../writing-cards/LN02-生活被打断.md)
   - 一次情绪从失望转到意外的开心 → [情绪小转折](../writing-cards/LN07-情绪小转折.md)
   - 讲到最后揭晓“我也在里面” → [最后揭晓关系](../writing-cards/LN15-最后揭晓关系.md)
   - 用行动让人重新认识自己 → [击碎标签](../writing-cards/LN01-击碎标签.md)
   - 每一步选择都带来下一步，一环扣一环 → [因果接力](../writing-cards/LX06-因果接力.md)
   - 明明有退路，他还是按自己的性子选了那条路 → [性格推动选择](../writing-cards/LX07-性格推动选择.md)
   - 答完一个问题又冒出下一个，最后落到一个大问题 → [问题接力](../writing-cards/LX21-问题接力.md)
   - 一件普通的事，每一步都不容易 → [困境层层展开](../writing-cards/LN06-困境层层展开.md)
   - 从一个具体的不便，讲到某个行动带来的改善 → [缺憾到改善](../writing-cards/LN17-缺憾到改善.md)
   - 一路在解决的问题，最后发现前提立不住 → [前提翻转](../writing-cards/LX10-前提翻转.md)
   - 都不贴 → [三幕式](../writing-cards/LX05-三幕式.md)。它也有自己的条件：中段要有人物的行动，不能只有开头出事、结尾成功。
3. **整篇组织卡也都对不上**：告诉用户现有卡库里没有合适的讲法，说清这份材料是什么样的。这和缺料是两回事：缺料要去补材料，这种情况以后可以补一张卡。
