# LX04 让关系照出人物：帮手互补，对手施压

暂无完整案例，只给骨架。

**层级：人物关系。** 原课方法与例子提供依据；卡名、准入条件、段落安排及字数为本次整理。整篇骨架不等于新的题材分类，局部卡只能插入相应环节。

## 1. 讲什么、主线看哪里

**讲什么**：让人物与一个真实的合作者或对手互动，通过不同做法看见他的能力、短处和关系。

**主线看哪里**：配角做了什么，怎样改变主角的行动；不能只用来夸主角。

## 2. 准入条件

- [ ] 有真实关系和一件互动中的具体事。
- [ ] 双方至少有一个能力、目标或处境差异。
- [ ] 能交代互动后的改变；合作和对抗可以择一使用。

**适合的材料**：搭档、师徒、同事、竞争关系的故事场景。

**红线**

- 不为了衬托而把真实伙伴写笨。
- 对手厉害或邪恶要有事实依据。
- 人物关系不能由功能需要而虚构。

**缺了怎么办**：只有一个人的行动可看LX02；有对话但关系不清可看LX19。
