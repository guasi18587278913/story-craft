# LX07 性格推动选择：有退路，他仍选了那条路

有完整课堂短例，仅支持本卡标明的层级；不是已验证的口播成稿。

**层级：整篇骨架。** 原课方法与例子提供依据；卡名、准入条件、段落安排及字数为本次整理。整篇骨架不等于新的题材分类，局部卡只能插入相应环节。

## 1. 讲什么、主线看哪里

**讲什么**：人物本可以选另一条路，但他的欲望、信念或弱点让他作出某个选择，最后承担后果。

**主线看哪里**：人物为什么这样选；不是编一个意外让他被动走向结局。

## 2. 准入条件

- [ ] 存在真实可选的另一条路。
- [ ] 当事人的动机、信念或反复行为有证据。
- [ ] 选择和后果之间有可交代的联系。

**适合的材料**：人物决策、犯错复盘、成功与代价的故事。

**红线**

- 不靠标签诊断一个人的心理。
- 别把课程对虚构人物的解释当成真人动机证据。
- 承认环境限制，不把一切结果都归结为性格。

**缺了怎么办**：只有行为没有动机材料，先按LX06写可证实因果；两个价值都舍不得可用LX24。

## 4. 完整案例

### 约翰越狱后的复仇选择

来源：04 情节：怎样让故事既合理又惊奇（得到《跟着李新学编剧》），第65—69行；课程对虚构影视的转述。第三人称，未核对剧集；人设解释为课程观点。

> 举个例子。美剧《越狱》很多人都看过，在剧里面，意大利黑手党大哥约翰在成功脱狱后逃到了自己帮派羽翼的保护之下，可谓全身而退。

> 按照一般人的逻辑，他此后应该低调行事，从此人间蒸发，享受家庭幸福生活才对。可是，在这部剧里，约翰并没有这么做。他在听到仇人在附近现身的消息后，再次冒险前去刺杀，全然不顾家人的反对，最后落入警察圈套被击毙身亡。

> 编剧之所以设计这个情节，就是遵照了“人设原则”，因为约翰是一个有仇必报，眼里揉不得沙子的人。他这么做是合理的。

**这一篇怎么推进**

- 先给安全退路，再给仇人出现的诱因。
- 人物主动放弃退路，行动招致结果；课程随后解释人设。
