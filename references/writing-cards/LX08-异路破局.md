# LX08 异路破局：目标猜得到，办法猜不到

有完整课堂短例，仅支持本卡标明的层级；不是已验证的口播成稿。

**层级：局部破局场景。** 原课方法与例子提供依据；卡名、准入条件、段落安排及字数为本次整理。整篇骨架不等于新的题材分类，局部卡只能插入相应环节。

## 1. 讲什么、主线看哪里

**讲什么**：主角为了一个明确目标，使用出乎常规但有条件支持的办法，同时交代这个办法的代价。

**主线看哪里**：惊奇来自手段；目标仍清楚。解决办法不能凭空从结尾掉下来。

## 2. 准入条件

- [ ] 目标及常规办法的限制已经明确。
- [ ] 非常规办法的资源、条件或前期线索有根据。
- [ ] 实际效果和代价能交代。

**适合的材料**：真实项目里的改法、技术或经营破局；虚构剧情的解套。

**红线**

- 写真人不能从电影复制不存在的工具或能力。
- 办法新奇不等于有效，结果按证据。
- 保留副作用与代价，不只写爽点。

**缺了怎么办**：只是新信息改变理解可用LX09或LX10；普通办法持续尝试可用LX14。

## 4. 完整案例

### 魔术师用复制完成魔术

来源：04 情节：怎样让故事既合理又惊奇（得到《跟着李新学编剧》），第77—77行；课程对虚构电影的转述。第三人称；奇幻科技及伤亡是影视情节，不是现实可行办法，未核对原片。

> 比如在电影《致命魔术》中，主角魔术师眼看自己竞争对手的魔术造诣已经远超自己，心生嫉妒。我们作为观众虽然知道他一定会采取行动试图反败为胜，但是我们想象不到的是他所使用的手段，是利用特斯拉的黑科技在魔术表演中自我复制，制造“大变活人”的神奇效果，但是每次表演结束，他都会淹死自己的复制人。这个脑洞实在是诡异而不可捉摸。

**这一篇怎么推进**

- 观众能猜到主角想反败为胜，却猜不到复制的手段。
- 原文紧接着写每次表演的代价，惊奇不只来自成功。
