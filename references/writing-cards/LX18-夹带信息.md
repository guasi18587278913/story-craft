# LX18 夹带信息：借表面话题让另一条信息露出来

暂无完整案例，只给骨架。

**层级：局部台词。** 原课方法与例子提供依据；卡名、准入条件、段落安排及字数为本次整理。整篇骨架不等于新的题材分类，局部卡只能插入相应环节。

## 1. 讲什么、主线看哪里

**讲什么**：人物谈一个表面话题，同时让另一个真正想传达的信息被听见。

**主线看哪里**：两层信息有没有自然联系；这不是旁白替人物总结品质。

## 2. 准入条件

- [ ] 表面话题在当前场合成立。
- [ ] 要传达的信息有事实或虚构设定支持。
- [ ] 对方能从原话和情境中读出另一层。

**适合的材料**：人物说话方式、炫耀或掩饰的故事描写；不作为夸大自我宣传的话术。

**红线**

- 不能用这种方式虚报收入、资产、履历。
- 真实引语逐字保留，不加工成更显眼的暗示。
- 不要隐藏需要明确披露的商业利益关系。

**缺了怎么办**：无法自然携带第二层信息就直说；借比喻持续交流用LX17。
