# LX24 两难见人：两样都重要，他必须舍掉一样

暂无完整案例，只给骨架。

**层级：整篇选择骨架。** 原课方法与例子提供依据；卡名、准入条件、段落安排及字数为本次整理。整篇骨架不等于新的题材分类，局部卡只能插入相应环节。

## 1. 讲什么、主线看哪里

**讲什么**：人物面对两个不能兼得的重要东西，作出选择并承受代价，让人从取舍中看见他在乎什么。

**主线看哪里**：两边的价值与损失都成立，不是把正确答案伪装成困难选择。

## 2. 准入条件

- [ ] 有真实不能兼得的选项或明确虚构设定。
- [ ] 每个选项对当事人都重要，材料说明代价。
- [ ] 有实际选择与后果；未选择时如实停在当下。

**适合的材料**：人生选择、职业取舍、关系冲突；虚构剧作的极端场景。

**红线**

- 真人不能人为删去第三条可行路制造假两难。
- 不把自己的价值排序当成当事人的动机。
- 极端的生命选择是课中影视例子，不泛化为现实常态。

**缺了怎么办**：只是目标逐渐变化看目标转向；主要是性格导致选错路看LX07。
