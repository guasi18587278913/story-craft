# 喜好入口：从对方喜欢的东西接到本题

暂无完整案例，只给骨架。

**用途层级**：开头／关系建立卡。不是独立故事题材的卡，不能与整篇故事类型混算。

**来源性质**：原课深耕喜好，整理为叙述入口。

## 1. 讲什么、主线看哪里

**讲什么**：先呈现听众熟悉喜欢的东西，再交代它与本题的真实联系。

**主线看哪里**：看联系能否兑现，不是吸引来后换题。

## 2. 准入条件

- [ ] 知道喜好的依据明确。
- [ ] 兴趣对象与本题有真实关联。
- [ ] 后文兑现入口。

**适合的材料**：特定兴趣人群开场、自我介绍、熟悉事物引入陌生话题。

**红线**

- 不挖隐私或编绯闻。
- 不暗示虚构名人背书或合作。
- 不按人口身份推定个人喜好。

**缺了怎么办**：不知道喜好用LN23；共同处境用LN16。
