# 生活被打断：努力恢复原样，却一再受阻

暂无完整案例，只给骨架。

**用途层级**：整篇故事骨架。不是独立故事题材的卡，不能与整篇故事类型混算。

**来源性质**：原课三阶段“生活遭遇变量—意外打断努力—情感满足”。

## 1. 讲什么、主线看哪里

**讲什么**：原有生活被打断，主角努力挽回却再次受阻，最后交代行动与情感的去向。

**主线看哪里**：看生活对主角的意义，以及每次努力如何改变局面。

## 2. 准入条件

- [ ] 原来的生活及其重要性明确。
- [ ] 有破坏平衡的变化和实际努力。
- [ ] 能诚实交代结果或当前卡点。

**适合的材料**：生活转折、关系变化、突发事件、项目受挫。

**红线**

- 不编苦难、两难或内心。
- 情感交代不等于必须圆满。
- 原课也注明麦基本人说的是原理，不把它当通用定律。

**缺了怎么办**：没有过程只有消息，用LN04；反复排查同一原因，用折腾经历。

**原课还要保留三项检查**：
- 两难冲突（第41–43行）：两边各有理由与代价。写清所求、相反义务、选择；不是设一个坏人。课上感情例只有处境，没有后续结果。
- 逻辑悬念（第61–63行）：追问发生了什么或原因是什么，结尾回应同一问题。
- 情感悬念（第65–73行）：即使知道客观结局，仍关心关系怎样走到那里，需完成关系线。
海景段第47与49–51行是同题开场改写，不是换题材仿写。
