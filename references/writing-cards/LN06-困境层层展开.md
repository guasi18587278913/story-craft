# 困境层层展开：普通事每一步都不容易

暂无完整案例，只给骨架。

**用途层级**：整篇故事骨架。不是独立故事题材的卡，不能与整篇故事类型混算。

**来源性质**：原课困境原则的外部困难部分。

## 1. 讲什么、主线看哪里

**讲什么**：把普通事情拆开，逐步露出忽略的难处，交代应对与结果。

**主线看哪里**：每步难在哪、做了什么，不能只反复说难。

## 2. 准入条件

- [ ] 有明确任务。
- [ ] 有至少两种真实障碍。
- [ ] 有行动与结果或当前卡点。

**适合的材料**：劳动、办事、交付、活动。

**红线**

- 不把“也许”假设写成履历。
- 不为转折编困难。
- 不把3分钟经验当短视频定律。

**缺了怎么办**：只有一次困难照实写一次；反复查同一原因用折腾经历。
