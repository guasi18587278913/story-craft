# 探照灯：让一个具体细节承担你的意思

有完整课堂短例或完整局部示范；未经过实际写稿验证。

**用途层级**：局部表达与选材用法；可嵌入开头、故事中段或观点段。不是独立故事题材的卡，不能与整篇故事类型混算。

**来源性质**：原课明确命名“探照灯式讲述”；骨架将注意力集中、细节呈现与意义回扣整理为操作步骤。

## 1. 讲什么、主线看哪里

**讲什么**：不把所有信息一次性讲完，挑出少数能让人感受到重点的细节，带着听众看见它们。

**主线看哪里**：看细节能否让人理解此处的意思；不是细节越多越好，也不是省掉反面事实。

## 2. 准入条件

- [ ] 有一个清楚的表达重点。
- [ ] 有与重点有关、可核对的具体细节。
- [ ] 能够说明细节支持到什么程度，不以偏概全。

**适合的材料**：观察见闻、人物细节、参观经历、能力展示、解释一个抽象观点。

**红线**

- 不把假设描述改成亲身见闻。
- 不能靠一个细节证明它撑不起的整体能力。
- 取舍不等于隐藏会改变结论的重要条件。

**缺了怎么办**：没有现场细节就先补材料；几个画面靠尺度或情绪相连，可看 LN24 全景与特写、LN25 相似画面组接。

## 4. 完整案例

### 香料公司的喷泉

完整课堂短例，第一人称参观自述；未独立核验。原文“合成世界上的任何一种味道”是老师由体验生发的感受，不是对该企业全部技术能力的检验结论。

原文第33–33行：

> 比如，我曾经拜访过一家世界著名的香料公司，这其实是个化工企业。你说，一个化工企业应该怎么才能证明自己是个实力强、研发强的公司？我们想象中肯定是开阔的厂房、科技感的展览馆，对不对？但人家没这么干，它的做法是：在公司大楼门口修了一个喷泉，水里加入香料，每隔几分钟，就换个味道。一会儿是巧克力味儿的，一会儿是薄荷味儿的。你站在喷泉前面看一会儿，都不用导游讲解，你自然而然就会意识到，哦，这家公司有能力，合成世界上的任何一种味道。这个实力不就展现出来了吗？

**这一篇怎么推进**

- 从“怎么证明实力”的问题起步，随后只照亮喷泉与气味变化。
- 观众通过一处体验理解讲述者的感受，不必听一整套企业介绍。
- 卡片用于真实材料时，把看见的事实和据此产生的判断分开。
