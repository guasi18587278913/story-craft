# 情绪小转折：从失望讲到意外的开心

有完整课堂短例或完整局部示范；未经过实际写稿验证。

**用途层级**：短故事／中段卡。不是独立故事题材的卡，不能与整篇故事类型混算。

**来源性质**：原课细化情绪，区别于外部多轮困境。

## 1. 讲什么、主线看哪里

**讲什么**：小事不变，把期待、失望和情绪改变的那个动作写出来。

**主线看哪里**：情绪因什么具体事情改变。

## 2. 准入条件

- [ ] 有本人表达的情绪。
- [ ] 有具体触发事件。
- [ ] 有行动反馈。

**适合的材料**：等待、小成功、误会消除、日常经历。

**红线**

- 不编他人内心。
- 不把事后领悟放回当时。
- 不拔高成命运改变。

**缺了怎么办**：无情绪证据写过程；多重外部困难用LN06。

## 4. 完整案例

### 只钓到一条鱼（完整课堂短例）

老师以“大概率是这样的”构造的第一人称假设，不是作者或用户真实经历。

原文第65–65行：

> 比如，你说，我昨天去钓鱼，只钓到了一条。这么说出来，其实很平常。但你可以想想自己昨天的情绪是怎么样的，大概率是这样的：我昨天去钓鱼，在太阳底下晒了一整天，连个鱼影也没看见，什么都没钓着。真的好失望啊。就在我开始收拾东西，准备走人的时候，你猜怎么着？鱼漂突然动了。我赶紧提起竿一看，上面真有一条大鱼，太走运了。你看，这种由失望到开心的情绪变动，也是一种困境，它也有转折。就要比你直接说昨天只钓到一条鱼好很多。

**这一篇怎么推进**

- 把信息“只钓到一条”展开成等待与失望。
- 收东西是低点，鱼漂动了是触发。
- 提竿、见鱼、开心完成一轮，不编第二轮。
