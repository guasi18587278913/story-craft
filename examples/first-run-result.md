# 社区书店短故事口播

以下是合成教学示例，不是真实书店案例。只做了本地核查；外部首读、另一模型审稿及独立上下文复核均未完成，本次没有外发。

---

社区书店里，预约书和待归还的书，原来混在一起放。

店员小林把书架分成两区：一区放预约书，一区放待归还的书。预约书上，还写了取书日期。

这样调整以后，取错书会不会变少？

试行一周，记录了一次取错书。那比以前少了吗？

可是，改动前到底错拿过几次，现在没有这个数。少了前后的比较，取错书到底有没有变少，还看不出来。

---

这版面向普通读者，第三人称，讲的是小林做了什么、试行后还不知道什么。共131字，按288字/分钟估计约27秒，未配音，实际时长未测。

这次用了“问题接力”：从“这样调整以后，取错书会不会变少”接到“一周的记录”，最后交代缺少改动前数据，所以还看不出来。照骨架试写，没有完整案例可照；未采用需要三步以上的“过程记录”，也未采用“讲别人怎么做成的”。

改稿把“一次，到底算多还是算少”收窄为“那比以前少了吗”，让问题与现有证据对应；结尾去掉重复的分区动作，保留为什么无法判断。

仍缺的是改动前的可比记录与效果证据，因此本稿不讲减少了多少，也不把小林写成解决了问题。人物对话、心理和顾客反应都没有补写。
